# Security Policy

## Supported Versions

Only the latest version of Jules Console is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Jules Console seriously. If you believe you have found a security vulnerability, please do **not** report it via public issues.

Instead, please send an email to **dangtrinh.ha@gmail.com**.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact if exploited.

We will acknowledge your report within 48 hours and provide a timeline for resolution.
