# Contributing to Jules Console

Thank you for your interest in contributing to Jules Console! We welcome contributions from the community to help make this dashboard more robust and feature-rich.

## 🚀 Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** to your local machine:
    ```bash
    git clone https://github.com/your-username/jules-console.git
    cd jules-console
    ```
3.  **Set up the development environment**:
    ```bash
    npm run setup
    ```
4.  **Create a branch** for your feature or fix:
    ```bash
    git checkout -b feature/amazing-feature
    ```

## 🛠️ Development Workflow

-   **Start Dev Server**: `npm run dev`
-   **Run Tests**: `npm run test`
-   **Lint Code**: `npm run lint`
-   **Build Check**: `npm run build`

Please ensure all tests pass and there are no linting errors before submitting a pull request.

## 📝 Coding Standards

-   Use **TypeScript** for all new code.
-   Follow the existing **functional React** patterns and hooks.
-   Use **TailwindCSS v4** for styling.
-   Maintain 100% functional parity with existing features when refactoring.

## 📥 Submitting a Pull Request

1.  **Sync your fork** with the upstream repository.
2.  **Commit your changes** using descriptive commit messages.
3.  **Push to your fork** and submit a Pull Request.
4.  **Describe your changes** in detail in the PR template.
