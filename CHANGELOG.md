# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-03-16

### Changed
- **Architectural Refactor**: Centralized GitHub `Octokit` configuration with default headers and consistent error handling in `src/lib/github.ts`.
- **Logic Decoupling**: Extracted Jules session mapping logic from hooks into a dedicated `mapJulesSession` utility in `src/lib/jules.ts`.
- **Hook Optimization**: Refactored `useJules` hook to reduce complexity and improve maintainability by delegating data transformation to the library layer.
- **Type Safety**: Enhanced type definitions for API errors across the core communication layer.

### Security
- **Dependency Patching**: Resolved 2 high-severity vulnerabilities in `flatted` and `undici` through `npm audit fix`.
- **Link Hardening**: Applied `rel="noopener noreferrer"` to all `target="_blank"` links across UI components to prevent reverse tabnabbing attacks.

## [0.1.0] - 2026-02-27

### Added
- **Hugging Face RepoGroup Integration**: Complete management suite for HF Models, Spaces, and Datasets.
- **Unified Inbox**: Cross-provider signal aggregation for GitHub and Hugging Face.
- **AI-Powered Audits**: "Analyze with Jules" synergy for Hugging Face assets via repoless sessions.
- **DevEx Infrastructure**: Bootstrapped `.devcontainer`, `.editorconfig`, and CI/CD via GitHub Actions.
- **Identity Profiles**: Multi-token management system for switching between different AI/Dev contexts.

### Changed
- Refactored `JulesAccount` to `ProviderProfile` to support multi-provider tokens.
- Updated `SettingsModal` for multi-token management.
- Standardized TypeScript version to `~5.7.3` for stability.

### Security
- Implemented `npm audit` and secret scanning protocols in CI.
